# Reference input data

These CSVs are deterministic synthetic signals generated by the repository's reference data generator. They provide a self-contained quickstart without private research files or MATLAB.

Each file has 500 rows sampled at 2.5 kHz and three columns: `i_a`, `i_b`, and `i_c`. They are simplified reference inputs and must not be presented as real motor measurements.

```bash
python scripts/run_demo.py --input data/demo/phase_open_window.csv --output reports/demo_phase_open.json
```
