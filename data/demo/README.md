# Public demo data

These CSVs are deterministic synthetic signals generated by the repository's public demo generator. They are included so a reviewer can run the Agent without private research files or MATLAB.

Each file has 500 rows sampled at 2.5 kHz and three columns: `i_a`, `i_b`, and `i_c`. They are deliberately simplified demonstrations and must not be presented as real motor measurements.

```bash
python scripts/run_demo.py --input data/demo/phase_open_window.csv --output reports/demo_phase_open.json
```
